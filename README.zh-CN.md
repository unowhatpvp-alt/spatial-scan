# Spatial Scan

在浏览器本地完成的摄影测量工具：采集重叠照片，计算真实三维点，并导出结果。扫描内容不上传。

[打开网页](https://unowhatpvp-alt.github.io/spatial-scan/) · [English](README.md)

当前版本是实验性的**三维点云重建**。它从多个真实视角估计相机运动并进行三角测量，不保证完整房间、闭合网格或测量级尺寸。

## 可以做什么

- 手动或自动采集摄像头画面，也可导入照片。
- 使用 ORB 特征、多视角几何、PnP 定位与可选的局部立体匹配，计算带颜色的三维点。
- 交互查看点云，将模型保存到此浏览器的本机模型库。
- 导出 GLB 点几何或带颜色的 PLY，供后续处理。
- 切换中英文、浅色与深色模式，准备离线引擎。

扫描计算全部在设备内完成。网页只从同一站点下载静态文件和约 11 MB 的 OpenCV/WebAssembly 引擎；没有扫描上传接口、统计追踪、第三方运行时请求或云端推理。点击 GitHub 链接时才会跳转到 GitHub。

## 开始扫描

1. 通过 HTTPS 打开网页，选择光线均匀、静止且纹理丰富的小物体。建议先扫描物体的一侧。
2. 开启摄像头，或按拍摄顺序导入照片。保持相同镜头、缩放、方向与宽高比。
3. 围绕物体缓慢横向移动，保留约 70–80% 的相邻画面重叠。原地转动没有足够视差。先采集 8–16 张；界面至少需要两张。
4. 在“扫描设置”中检查水平视场角。默认 60° 是估计值，不等同于相机标定。
5. 开始重建，检查有效视角数与重投影误差，再旋转点云观察形状。
6. 导出 GLB、PLY，或保存到本机模型库。导出缩放倍数仅改变相对坐标，不会自动获得真实尺寸。

GLB 使用 glTF 的 `POINTS` 点图元，并非三角网格。不同查看器与导入器对点图元的支持不同；PLY 提供带颜色顶点作为替代。导入 Blender 也不会自动生成完整表面。

离线使用前，请在线打开网页，等待后台准备完成；如需重试，可点击“准备离线引擎”。确认缓存就绪后，再离线打开同一网址。浏览器可能清理缓存，隐私模式、相机权限和存储限制也可能影响离线使用。重要结果请导出备份；清除网站数据会删除本机模型库。

## 设备与限制

| 设备或能力 | 当前范围 |
| --- | --- |
| 现代桌面浏览器 | 摄像头或照片输入、本地 WASM 计算、WebGL2 预览 |
| iPhone/iPad Safari | 提供摄像头与照片流程，尚未完成实机质量及稳定性验证 |
| 低内存设备 | 较小的处理分辨率，最多 24 张；较高性能配置最多 32 张 |
| 硬件深度 | 未接入 ARKit、iPhone LiDAR 或 WebXR 深度 |

白墙、重复纹理、反光、透明、移动物体和模糊画面通常无法可靠重建。估计内参、镜头畸变、重叠不足、漂移及缺少全局束调整都会影响精度。局部立体匹配只在图像证据充分时增加三维点，无法补全所有空洞。当前使用经典视觉算法，不下载神经深度模型。

已验证合成多视角场景、一组公开的已校正立体照片，以及桌面浏览器中的照片重建、本机模型持久化、GLB 下载和 Blender 点导入。这些验证不能证明手持扫描、iPhone 实机或完整房间的表现。详见[验证记录](docs/validation.md)。

## 本地开发

需要 Node.js 22 或更新版本、pnpm 11.25.0。

```sh
pnpm install --frozen-lockfile --ignore-scripts
pnpm test
pnpm build
pnpm dev
```

开发服务器在 `http://127.0.0.1:4173` 提供已构建的 `dist/`；修改源码后需重新构建并刷新。

仓库只保留源码、测试与锁文件，不提交依赖、生成产物或本地验证照片。推送到 `main` 后，GitHub Actions 运行测试、构建并部署 Pages。Fork 后请在 **Settings → Pages → Source** 选择 **GitHub Actions**，并按需修改项目链接。
